TURN-BASED GAME IN JAVA FOR CBL PROJECT

OVERVIEW:
This project implements a simple turn-based combat game inspired by the Pokémon battle system.
The program was developed using Java and the Swing library to demonstrate the principles of object-oriented programming (OOP), event-driven user interfaces, and modular design.
The main learning goal was to integrate object-oriented logic (entities, controllers, UI panels) with graphical interface management using Swing components and layout managers.

LEARNING OBJECTIVES:
Apply OOP principles such as classes, interfaces, inheritance etc.
Implementation of a modular game architecture separating logic and UI.
Use Java Swing for graphical user interface design.
Use Git to collaborate and contribute to the project simultaneously, allowing to retrieve previous versions of the code.
Explore different options to enhance User Experience, such as difficulty selection, message narration, separated menu panels for navigation

GAME MECHANICS:
The combat follows a turn-based sequence:

- The player and the enemy both have defined HP (Health Points) and attack values.
- The player selects an action (e.g., Attack or Special Move).
- After a short timer delay, the enemy performs its move.
- The HP bars update dynamically after each action.
- The game ends when either side’s HP reaches zero.

HOW TO RUN:
1. Ensure Java 17 or later is installed
2. Compile the source files: src/GameFrame.java
3. Run the main class: game.GameFrame
